# Kaart kunstonderwijs

Interactieve Streamlit-applicatie voor het bekijken van opleidingen en varianten binnen het Nederlandse kunstonderwijs.

## Functionaliteiten

- Filteren op opleidingsclusters
- Filteren op variantclusters
- Geografische weergave van opleidingen
- Geografische weergave van varianten
- Studentenaantallen per opleiding
- Arbeidsmarktinformatie
- Downloaden van geselecteerde gegevens naar Excel

## Lokaal starten

Installeer de benodigde packages:

pip install -r requirements.txt

Start vervolgens de applicatie:

streamlit run app.py
